# Technical Support Portfolio

## About Me

I am an Information Technology student at BYU-Pathway Worldwide, building foundational knowledge and practical skills in technical support, computer hardware, operating systems, networking, and IT troubleshooting.

This portfolio documents projects completed as part of my coursework in **PC Hardware Technician** and **Introduction to Information Technology** . It highlights my learning process, technical exercises, troubleshooting approaches, and the evidence of my work.
